<objective>
Create a Nango sync that pulls OpportunityHistory records from Salesforce for downstream stage velocity analysis.

Purpose: OpportunityHistory provides stage change timestamps needed to derive time-in-stage metrics. Unlike Opportunity which tracks current state, OpportunityHistory is an audit log of every Amount/Stage/CloseDate/Probability change -- essential for pipeline velocity reporting.

Output: Working `fetch-opportunity-history.ts` sync registered in index.ts, pulling all HIST-01 fields with CreatedDate-based incremental filtering (HIST-02) and proper ordering (HIST-03).

OpportunityHistory SOQL from spec (Report 2):
```sql
SELECT Id, OpportunityId, StageName, Amount, CloseDate, Probability,
       ForecastCategoryName, CreatedDate, CreatedById
FROM OpportunityHistory
WHERE IsDeleted = false
ORDER BY OpportunityId, CreatedDate ASC
-- For incremental: AND CreatedDate > {last_pull_timestamp}
```

Key differences from Opportunity sync:
- No nested relationships (flat table)
- Use CreatedDate for incremental filter (history records are immutable, no LastModifiedDate changes)
- ORDER BY clause required for stage velocity derivation

- `CloseDate: sfDate` (date string YYYY-MM-DD)
- `Probability: sfPercentage` (nullable number 0-100)
- `ForecastCategoryName: sfNullableString` (nullable picklist)
- `CreatedDate: sfDateTime` (when change occurred)
- `CreatedById: sfId` (user who made the change)

**SOQL field list constant:**
```typescript
const OPPORTUNITY_HISTORY_SOQL_FIELDS =
    'Id, OpportunityId, StageName, Amount, CloseDate, Probability, ForecastCategoryName, CreatedDate, CreatedById';
```

**Query builder function (buildOpportunityHistoryQuery):**
- Takes optional `lastSyncDate?: Date` parameter
- Base query: `SELECT {fields} FROM OpportunityHistory WHERE IsDeleted = false ORDER BY OpportunityId, CreatedDate ASC`
- When `lastSyncDate` provided, add `AND CreatedDate > {ISO date}` BEFORE the ORDER BY
- Note: ORDER BY is critical for HIST-03 (velocity derivation requires sequential stage changes per opportunity)

**createSync definition:**
- description: 'Fetches Salesforce OpportunityHistory records for stage velocity analysis.'
- version: '1.0.0'
- endpoints: `[{ method: 'GET', path: '/salesforce/opportunity-history', group: 'OpportunityHistory' }]`
- frequency: 'every hour'
- autoStart: true
- syncType: 'incremental'
- metadata: z.void()
- models: `{ OpportunityHistory: opportunityHistorySchema }`

**exec function:**
- Build SOQL using `buildOpportunityHistoryQuery(nango.lastSyncDate)` -- lastSyncDate is a PROPERTY not a method
- Paginate using `nango.paginate({ endpoint: queryEndpoint(soql), paginate: salesforcePaginationConfig, retries: 3 })`
- Map each batch record: add lowercase `id` from `raw['Id']`, parse with schema
- Call `nango.batchSave(records, 'OpportunityHistory')`
- Log record count

**Export:**
