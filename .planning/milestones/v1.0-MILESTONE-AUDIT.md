## Tech Debt by Phase

### Phase 02: Persistence & Data Flow

1. **session.py helpers unused in production** — `create_engine` and `create_session_factory` from `session.py` are only used in tests. `app.py` lifespan reimplements engine creation inline. Risk: configuration drift between test and production paths.

### Phase 03: Webhook Transport & Observability

1. **No automated migration** — `app.py` lifespan does not run Alembic migrations. Fresh database requires manual `alembic upgrade head` before the service will work.

2. **Events not consumed** — `InMemoryEventPublisher` stores `DataAddedEvent` instances but nothing reads them. Events are silently dropped. This is acceptable for v1 (event publishing mechanism is wired), but downstream consumers are needed for v2.
