# Roadmap: data-hub

**Project:** Data webhook ingestion platform with strict validation
**Core Value:** Data from connected integrations flows reliably into the platform with strict validation — if it's in the database, it's valid.
**Granularity:** Coarse (3 phases)
**Created:** 2026-03-18

## Phases

- [x] **Phase 1: Foundation & Kernel** - Pure business logic with zero dependencies
- [x] **Phase 2: Persistence & Data Flow** - SQLite repository with audit trail and idempotency (completed 2026-03-18)
- [x] **Phase 3: Webhook Transport & Observability** - FastAPI endpoints with signature verification and structured logging (completed 2026-03-19)

## Phase Details

### Phase 1: Foundation & Kernel
**Goal**: Pure business logic establishes domain model, validation rules, and port interfaces

**Depends on**: Nothing (first phase)

**Requirements**: KERN-01, KERN-02, KERN-03, KERN-04, KERN-05

**Success Criteria** (what must be TRUE):
1. AddDataCommand accepts table name, source ID, schema hint, and raw data with no external dependencies
2. Schema validation rejects malformed data and returns clear validation errors before any persistence attempt
3. DataAdded event emitted after successful validation containing record metadata
4. Port interfaces (DataRepository, EventPublisher) defined as Python Protocols with no concrete implementations
5. Kernel module has zero imports from infrastructure libraries (SQLAlchemy, FastAPI, asyncpg)

### Phase 2: Persistence & Data Flow
**Goal**: Data reliably persists to SQLite (v1) with audit trail, idempotency guarantees, and verification capability

**Depends on**: Phase 1 (implements kernel ports)

**Requirements**: PERS-01, PERS-02, PERS-03, PERS-04, VERF-01

**Success Criteria** (what must be TRUE):
1. Data persisted to SQLite survives service restarts and transaction rollbacks (ACID guarantees)
2. Repository adapter implements DataRepository port without kernel knowing about SQLAlchemy/SQLite
3. Every data addition captured in audit trail with timestamp, source_id, table_name, and processing status
4. Duplicate webhook payloads with same event_id processed exactly once (no duplicate records)
5. Verification query returns stored data matching what was submitted in AddDataCommand

**Plans:** 3/3 plans complete

### Phase 3: Webhook Transport & Observability
**Goal**: External webhooks reliably received, authenticated, and processed with full observability

**Depends on**: Phase 2 (uses persistence layer)

**Requirements**: TRAN-01, TRAN-02, TRAN-03, TRAN-04, OBSV-01, OBSV-02, OBSV-03

**Success Criteria** (what must be TRUE):
1. FastAPI endpoint receives Nango webhook POST and returns 202 Accepted within 5 seconds
2. Webhook signature verified on raw request bytes before any processing or parsing
3. Health check endpoint returns service status and database connectivity within 1 second
4. Every request traced with correlation ID appearing in all log entries for that request
5. Validation failures logged with full context (source_id, schema, data sample, error message)
6. Data quality metrics tracked and queryable: validation failure rate, processing latency (p50, p95, p99)

**Plans:** 3/3 plans complete

## Notes

**Architecture Pattern**: Hexagonal (Ports & Adapters) with CQRS
- Phase 1 builds kernel (zero dependencies)
- Phase 2 builds driven adapter (SQLite implements kernel ports)
- Phase 3 builds driving adapter (FastAPI uses kernel commands)

**Granularity**: Coarse (3 phases) — combines related concerns for streamlined delivery
- Phase 1: Setup + kernel domain logic
- Phase 2: Persistence + verification
- Phase 3: Transport + observability

**Critical Pitfalls Addressed**:
- Phase 1: Kernel purity enforcement, Pydantic validator performance
- Phase 2: Transaction boundaries (Unit of Work pattern), idempotency, Alembic async template
- Phase 3: Webhook signature verification on raw bytes, fast-ack pattern, structlog contextvars

**v2 Deferred**: Schema drift detection, automatic retry with backoff, complex transformation, real-time streaming, multiple storage backends, dead letter queue
